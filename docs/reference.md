<a id="cli"></a>

## CLI

`caty-gateway` has 6 subcommands. `python -m caty_gateway` is the same dispatcher.

### setup

```text
caty-gateway setup --member MEMBER [--backend BACKEND] [--port PORT] [--name NAME]
                   [--accent ACCENT] [--public-url PUBLIC_URL]
                   [--qr-delivery {auto,tty,url}] [--yes] [--plan-only]
                   [--health-timeout HEALTH_TIMEOUT] [--reset] [--status]
                   [--no-history] [--wait]
```

| Argument | Meaning |
|---|---|
| `--member` | Member id. Used for `CATY_ID`, the service name, and the storage location. Required |
| `--backend` | `claude` `codex` `openclaw` `hermes` `openai-compat`. `openai_compat` is normalized |
| `--port` | Listening port (default 8788). preflight FAILs if it is in use |
| `--name` `--accent` | Display name and accent color returned by `/identity` |
| `--public-url` | Destination URL shown in the QR. If omitted, generated from the Tailscale IPv4 |
| `--qr-delivery` | `tty` (render in the terminal) / `url` (show a delivery URL) / `auto` |
| `--plan-only` | Display the plan and the list of planned actions, then exit. Changes no files, service, or state |
| `--no-history` | Do not set `CATY_HISTORY_DIR` (no history is kept) |
| `--reset` | Discard only the resume metadata |
| `--status` / `--wait` | Show progress state / wait until a QR URL or a terminal state is reached |
| `--health-timeout` | Seconds to wait for `/health` (default 30) |

The generated `CATY_TOKEN` is only generated during install, and shows as `[REDACTED]` in the plan display.

### Others

| Command | Arguments |
|---|---|
| `status --member MEMBER [--wait]` | State of setup / supervisor |
| `serve` | Foreground start. Exits before starting if `CATY_GATEWAY_BIND` is not loopback and `CATY_TOKEN` is empty |
| `qr [--qr-delivery {auto,tty,url}] [--wait-visible-seconds N]` | Reissue the pairing QR |
| `push open-url URL --title T [--audience A] [--session S] [--key K]` / `push media URL --title T …` | Send an event to connected clients. `--title` is required. `CATY_TOKEN` is passed via an environment variable |
| `doctor --backend BACKEND [--port PORT] [--public-url URL]` | Passive preflight. `--probe` is reserved (returns FAIL in this release) |

### doctor items

12 common items: OS / Python / ffmpeg / ffprobe / tailscale executable / tailscale login / tailscale IPv4 / port / public URL / config directory / state directory / data directory. Backend-specific items are added: `claude version`, `claude working directory`, `claude credentials`; `codex version` and login state; `openclaw`'s executable and agent list; `hermes`'s key and `/v1/models`; `openai-compat models`. Exit code is 1 if any item FAILs.

## HTTP routes

All routes listen on the same port. Authentication is `Authorization: Bearer <CATY_TOKEN>`. Environments generated by `setup` always have `CATY_REQUIRE_AUTH=1` set.

| Route | Auth | Role |
|---|---|---|
| `GET /health` | required when `CATY_REQUIRE_AUTH=1` (always, in environments generated by `setup`) | `{"ok":true,"agent":…}` |
| `GET /identity` | required | Member id, display name, accent color |
| `POST /talk2` `GET /stream/<id>` | required | One voice turn (STT → backend → TTS stream) |
| `POST /see` | required | Passes voice + a screen frame to the backend |
| `POST /share` `GET /history` `GET /history/…` | required | Sharing attachments and conversation history |
| `GET /tts/voices` `…/preview` `…/voice-state` `…/voice-activations` | required | Voice listing, preview, state |
| `POST /push` | required | open-url / media events |
| `POST /pair/claim` | not required (source-restricted) | Exchanges the QR passphrase for a long-lived token. Only from tailnet or loopback |
| `POST /pair/new` `POST /pair/revoke` | required (write) | Reissue / revoke the passphrase |

The Bearer string is replaced with `[REDACTED]` in response headers and logs. Conversation content is not logged by default.

## Pairing contract v1 (summary)

The source of truth is [contracts/pairing-v1.md](contracts/pairing-v1.md). Only the values that matter operationally are extracted here.

| Item | Value |
|---|---|
| QR contents | `v` (=1), `url`, `pair` (`<8 hex>.<32 hex>`), `id`. Does not include the long-lived token |
| Passphrase expiry | 600 seconds (`CATY_PAIRING_TTL_SECONDS`) |
| Consumption | At-most-once. Deleted on success, leaving a consumed tombstone |
| Accepted sources | loopback, tailnet IPv4 `100.64.0.0/10`, Tailscale IPv6 ULA `fd7a:115c:a1e0::/48` |
| Consecutive failures | 60-second lockout after 5, expiry after 50 cumulative |
| Rate | Fixed 60-second window (`CATY_PAIRING_RATE_PER_MIN`) |
| Store | Disk-authoritative. Root 0700, records 0600, secret stored only as SHA-256, atomic replacement |
| Per member | One live passphrase. Issuing a new one expires the old one |

`CATY_PAIRING_ALLOW_NONTAILNET=1` is an unsupported switch that only removes the source restriction on claim; the restrictions on the QR-delivery side (IPv4 only, does not accept IPv6 ULA) are unchanged.

## Storage locations and permissions

| Kind | Path | Permissions |
|---|---|---|
| Environment file (Linux) | `~/.config/caty-gateway/<id>.env` | 0600 |
| Configuration directory | `~/.config/caty-gateway/<id>/` | user |
| Resume metadata / state | `~/.local/state/caty-gateway/setup/<id>.json` (deleted on success), `<id>.status.json` | 0600 |
| History | `~/.local/state/caty-gateway/history/<id>/` (under `XDG_STATE_HOME` if set) | user |
| Copies of bundled assets, filler audio | `~/.local/share/caty-gateway/<id>/assets` `…/fillers` | user |
| Pairing store | `~/.local/state/caty-gateway/pairing/` (override with `CATY_PAIRING_DIR`) | 0700 / 0600 |
| launchd | `~/Library/LaunchAgents/ai.caty.gateway.<id>.plist`, log `~/Library/Logs/caty-gateway-<id>.log` | user |

## Environment variable tiers

| Tier | Meaning | Examples |
|---|---|---|
| A | Relevant to every install | `CATY_ID` `CATY_BACKEND` `CATY_GATEWAY_PORT` `CATY_TOKEN` `CATY_PUBLIC_URL` |
| B | Backend-specific | `CATY_CLAUDE_CWD` `CATY_GCLI_BIN` `CATY_AGENT` `CATY_HERMES_URL` `CATY_OPENAI_BASE_URL` |
| B2 | Pairing safety thresholds | `CATY_PAIRING_TTL_SECONDS` `CATY_PAIRING_MAX_FAILURES` |
| C | Optional features | `CATY_TTS_ENGINE` `CATY_AVATAR_*` `ANTHROPIC_API_KEY` `CATY_HISTORY_MAX_TURNS` |
| D | Internal / test use (do not set) | `CATY_BACKEND_CONFIG_PATHS` and others |

The default value, where it is used, and whether it may be stored (member env 0600 / process-only) for each variable is authoritative in the table in [env.md](env.md); `make env-check` checks for drift against the generated file.
